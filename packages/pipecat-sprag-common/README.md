# pipecat-sprag-common

Shared configuration used by the Sprag Pipecat services. You won't normally install it directly; it comes in with `pipecat-sprag-llm`, `pipecat-sprag-stt`, and `pipecat-sprag-tts`.

See the [pipecat-sprag repository](https://github.com/sprag-ai/pipecat-sprag) for installation, usage, and examples.
